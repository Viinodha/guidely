## 💭 Why Guidely?

Choosing a career isn't as simple as answering a few questions about your interests.

For millions of students in India, it means navigating entrance examinations, college admissions, financial limitations, family expectations, eligibility criteria, and countless possible career paths.

Students have access to more information than ever, yet finding reliable information and understanding how it applies to their own circumstances remains a challenge.

Traditional career quizzes often offer generic recommendations without considering the realities of the Indian education system.

**Guidely aims to change that.**

Guidely is an AI-powered career and education guidance platform designed to help students explore their options, understand their possibilities, and make more informed decisions about their future.

Instead of telling students what they should become, Guidely helps them understand what they *could* become — and how to get there.

## ✨ Key Features

### 🤖 1. AI-Powered Career Guidance

* Personalized career exploration through AI.
* Guidance based on individual interests, goals, and circumstances.
* Conversational assistance to help students explore different possibilities.
* Support for making informed education and career decisions.

### 🎒 2. Guidance for School and College Students

Different stages of education require different kinds of guidance.

Guidely aims to support students across two major stages:

* **School students:** Explore streams, entrance examinations, undergraduate courses, and potential career paths.
* **College students:** Explore specializations, higher education, career opportunities, skill development, and alternative pathways.

### 🇮🇳 3. Built Around the Indian Education System

Career guidance should reflect the environment students actually live in.

Guidely focuses on the Indian context, including:

* Entrance examinations and admission pathways.
* Undergraduate courses and higher education options.
* Eligibility requirements and academic qualifications.
* Financial constraints and practical considerations.
* Multiple routes toward the same career goal.

### 🔮 4. What-If Career Simulator

What if you choose a different degree? What if you change your specialization? What if your original plan doesn't work out?

Guidely's proposed what-if experience helps students explore alternative decisions and understand their potential consequences.

The goal is to encourage exploration without making students feel that one decision determines their entire future.

### 🧠 5. Personalized Guidance and Context

Career decisions evolve as students learn more about themselves.

Guidely is designed around a more personalized experience, where relevant information about a student's goals, preferences, and progress can inform future guidance.

The aim is to make career exploration feel like a continuous process rather than a one-time quiz.

### 🎨 6. Interactive, Student-Friendly Experience

* A dedicated onboarding experience.
* Separate guidance journeys for school and college students.
* A responsive interface for different screen sizes.
* An interface designed to make complex decisions easier to explore.

## 🏗️ Getting Started

Want to explore Guidely locally or contribute to its development?

### Prerequisites

Make sure you have installed:

* [Node.js](https://nodejs.org/)
* npm
* Git

### 1. Clone the repository

```bash
git clone https://github.com/Viinodha/guidely.git
```

### 2. Navigate to the project directory

```bash
cd guidely
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

If the project uses external AI services or other integrations, create a `.env` file in the project root and configure the required variables.

For example:

```env
VITE_API_BASE_URL=your_api_base_url
```

Use the actual variable names expected by your application. Never commit API keys, passwords, or other secrets to GitHub. Private API credentials should remain on the server.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal to explore the application.

### 6. Build for production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🗺️ Future Scope

Potential areas for further development include:

* **Verified education data:** More comprehensive information about Indian colleges, courses, entrance examinations, and admission requirements.
* **Personalized roadmaps:** Actionable steps based on a student's current academic stage and long-term goals.
* **Decision comparison:** Compare alternative courses, colleges, and career pathways.
* **Financial awareness:** Explore education costs, scholarships, and more accessible alternatives.
* **Progress tracking:** Revisit goals and update plans as circumstances change.
* **Improved AI reliability:** Ground recommendations in credible sources and clearly distinguish verified information from AI-generated suggestions.

These are potential extensions, not a claim that every feature is already implemented.
